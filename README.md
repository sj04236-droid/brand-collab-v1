# brand-collab-v1 — 브랜드 협업 스킬

유튜브 채널 **여행 비밀노트**(https://www.youtube.com/@travelsecretnote)의 브랜드 협업(협찬·광고) 한 건을
**메일 진위 확인 → 단가표·견적 → 조건 합의 → 계약 검토 → 선금 → 시놉시스 → 제작 → 일부공개 검수 → 전체 공개(UTM) → 잔금**
순서로 진행하는 Claude Code 스킬입니다. (자동수익 챌린지 86강 과제)

## 설치
```
C:\Users\<사용자>\.claude\skills\brand-collab-v1\   ← 이 저장소 내용을 그대로 복사
```
Claude Code에서 "협찬 메일 왔어", "견적 보내", "시놉시스 써줘", "브랜드 콜라보로 진행해" 같은 말을 하면 스킬이 불립니다.

## 파일
| 파일 | 내용 |
|---|---|
| `SKILL.md` | 9단계 진행 규칙 (✋ = 사람이 승인해야 다음 단계) |
| `templates/rate_card.md` | 형식별 3단 단가표 (채널 숫자는 그날 API로 갱신) |
| `templates/emails.md` | 견적 회신 · 조건 확인 질문 · 검수 요청 · 잔금 요청 메일 틀 |
| `templates/synopsis.md` | 시놉시스 구글 문서 틀 |

## 실제 사용 예시

### 예시 1 — 브리프를 주고 시놉시스 받기 (2026-11-25 실제 실행)
**내가 AI에게 한 말**
> 브랜드 콜라보 스킬로 진행해. 광고주는 "출장 항공권 예약 대행"(https://airticket.hang0mall.com/booking/)이고, 브리프는 "출장이 잦은 직장인에게 예약 대행을 맡기면 시간과 숨은 비용이 줄어든다는 걸 알리고 예약 문의로 연결, 롱폼 8~10분, 과장·항공사 비방 금지". 연구해서 시놉시스를 구글 문서에 저장해.

**AI가 한 일과 결과**
1. 브리프에서 목표 행동(예약 문의) · 꼭 넣을 것(UTM 링크·고정 댓글) · 피할 것(과장·비방·확인 안 된 숫자)을 뽑음
2. 검색 수요(출장 항공권 / 항공권 변경 수수료 / 환불 규정), 채널 강점(발권 경력), 터진 영상 공식(답은 3분의 2 지점)을 합쳐 구성
3. 결과: 구글 문서 시놉시스 — 로그라인 "가장 싼 항공권을 끊었는데, 출장 일정이 한 번 바뀌자 총액이 뒤집힌다", 질문 1개, 답 공개 6분, 7개 구간별 내용·화면 기법, 협업 구간, 진행 일정
   → https://docs.google.com/document/d/1Jnrt9olY77j0BZQ_htbing1psYgKUVRbMyDRYLnQvVY/edit?usp=sharing

### 예시 2 — 의심스러운 협업 메일 확인 (0단계)
**내가 AI에게 한 말**
> 협찬 메일 왔어. "채널 소유권 확인을 위해 아래 링크에서 로그인해 주세요"라는데 진행해도 돼?

**AI의 답 (스킬 0단계 규칙)**
> 판정: **의심**. ① 발신 도메인이 브랜드 공식 도메인이 아닌 외부 헬프데스크 주소 ② "소유권 확인 + 로그인" 링크는 계정 탈취에 자주 쓰이는 형태. 링크를 누르지 말고, 브랜드 공식 사이트의 고객센터 주소로 직접 "이 메일을 보낸 게 맞는지" 문의하세요. 확인 전까지 견적 단계로 넘어가지 않습니다.

## 원칙
- 돈·서명·메일 발송·업로드는 사람이 직접. AI는 준비와 확인만.
- 숫자는 그날 API·공식 자료로만. 금융상품 추천·건강 효능 단정 금지.
- 비밀번호·API 키·계좌번호는 어떤 파일에도 쓰지 않음.
